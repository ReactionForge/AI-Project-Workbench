# 核心设计能力对照
project_id: ai-project-workbench
revision: v0.5.0-rc.1
role: observed_implementation
source: 本项目批准需求与实际源码对照；原始输入不公开

|设计能力|实际状态|边界|
|---|---|---|
|独立Projects与规范|真实封装、薄AGENTS/工作流/测试/决策入口|本App沙盒，不导入已有其他项目|
|同源现行知识|CURRENT指定可编辑Markdown，外部差异/旧状态拒写|有限语法；未知段落保留且阻止覆盖|
|意图/实现/提案|角色、生命周期、验证及最后核实独立|显式冲突人工关联；无语义引擎|
|精简任务/接手|相关知识、版本、下一步、证据、唯一导出|不启动外部AI；顺序接力|
|真实Git与源变化|所属repo提交/分支/index/dirty/untracked范围快照与SHA|linked worktree/子模块/外接配置拒绝；忽略/未登记范围不扫描|
|知识与证据验收|来源变化触发复核，保存当时提交|哈希关联不等于语义验收；无真实AI集成|
|中断/恢复|Markdown完整快照与原子CURRENT/日志恢复|夹具模拟，未真实断电/压力验证|
|项目内容备份|源码、Markdown/历史、输入、素材、数据、证据与登记引用；清单及Git摘要|缓存/凭据/链接/.git排除；任意嵌套链接不解析；1GiB上限|
|内容恢复|ZIP安全预览、本人确认、新独立副本、关闭后原生重开|保留原件；不覆盖原项目；不恢复Git对象/凭据|
|环境安装/清理|只读环境与边界说明|具体recipe与精确清理计划未落地；真实执行禁止|
|桌面可用性|中文原生WPF、空/错/未保存/取消/返回、内部实际控件与渲染|外部键鼠/物理DPI未运行；原生控制工具缺失，当前解锁未核验|
|并行/RAG/云同步|后置|不在本轮；不宣称加速收益|

v0.4仅补Git来源与内容恢复两个核心。本轮到有界交付，整个27页产品未全面生产验收。后续仍需外部桌面验收与用户授权下的实际项目使用反馈；不因此授权其他项目扫描、系统操作、真实AI账户或新模块。

|GitHub检查/审查计划|原生只读本地状态、已有gh API、目标绑定、精确diff/文件、候选关联及唯一导出|无远端写入口；历史/秘密完整审计及真实网络故障矩阵未完成，见PUBLICATION-PLAN.md|
